# Welcome to Access Collins

Access Collins is a hospitality venue booking management platform by The Access Group. It helps venues manage bookings, customers, and operations through a powerful suite of tools.

## Who are these docs for?

These docs are for **external integrators** — third-party developers, venue web developers, and partners who need to integrate with Collins. Whether you're building a server-to-server integration, embedding a booking form on a website, or pulling reporting data, you'll find the information you need here.

## What can you do with Collins?

Collins offers several integration paths:

- **Collins API** — manage bookings, customers, and venues via a RESTful API
- **Reporting API** — run optimised, read-only queries on bookings and retrieve notification-centre counts
- **Availability API** — check venue availability for dates, times, and covers
- **Booking Widget** — embed a ready-made booking form on your website

All API access is routed through the **Access Hospitality Integration Hub**, a central API gateway for the Access Group's Hospitality division.
